# Guia rápido — cep-ufv

1. Copie `projeto-exemplo.json` para `projeto.json` e preencha. Faltou dado? Deixe vazio — vira `[PREENCHER]`.
2. Gere:
```bash
python3 run.py projeto.json --out outputs-cep-meu-estudo/
```
3. Zere `outputs-cep-meu-estudo/pendencias.txt`.
4. Confira `10-Checklist-Conformidade` e siga o `12-Roteiro-Submissao` (ETAPA 0–8).
5. Folha de rosto sai da Plataforma Brasil (responsável = orientador). Nunca inicie a coleta antes da aprovação.
